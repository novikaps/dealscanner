# dealscanner
Reads a CIM (PDF) and drafts a **2–3 page first-screen memo** in Word:  1. About the company + investment highlights 2. Revenue mix 3. Customer mix 4. Financial snapshot, with growth and margins computed in Python 5. Comparable valuation, using your own comps CSV 6. Synergy hypotheses 7. Risks and challenges8. Key diligence questions
